# RAI Agency — Modelo "Finca Interactiva" como Producto Escalable

> Transcripción del PDF original. Nota de negocio, no código — contexto de por qué el proyecto se construye de forma reutilizable.

## La idea

El sistema construido para Quadro Café (fincas + avatar + geometría de extracción + Quadro Club) no es exclusivo de un café — es un **template de experiencia de marca** aplicable a cualquier negocio con origen/trazabilidad: cafeterías, chocolaterías, vinotecas, cervecerías artesanales, tiendas de té.

## Qué se replica sin cambios

- Arquitectura de módulos (Inicio / Carta / Origen-Fincas / Club / Lab educativo)
- Sistema de captura de email vía contenido premium bloqueado
- Estructura de fidelización por niveles (Quadro Club → renombrable por cliente)
- Pipeline de avatares 3D (Blender → Higgsfield) para contar historias de origen

## Qué cambia por cliente

- Paleta y tipografía (branding propio de cada marca)
- Datos reales: productos, proveedores/fincas, historias
- Nombre del programa de fidelización

## Modelo de negocio sugerido

- **Setup fee** por cliente (adaptación de marca + carga de datos): monto a definir según complejidad
- **Mensualidad** de mantenimiento/soporte (como el paquete de 2 meses ya ofrecido a Quadro)
- Quadro Café pasa a ser el **caso de estudio / portfolio** que vende el template a los próximos clientes
